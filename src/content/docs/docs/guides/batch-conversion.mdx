# Batch Conversion

Picmal's batch processing lets you convert hundreds of files at once with a single click. Perfect for converting photo libraries, website assets, or video collections.

## What is Batch Conversion?

Batch conversion means processing multiple files simultaneously:

- Convert entire folders of images or videos
- Apply the same settings to all files
- Save time compared to converting files one by one
- Maintain folder structure (optional)

## Basic Batch Conversion

### Convert a Folder of Images

1. **Add all files** - Drag a folder onto Picmal's window
2. **All files are added** - You'll see the complete list in the queue
3. **Choose format** - Select output format (applies to all)
4. **Set quality** - Adjust quality once for the entire batch
5. **Convert** - Click Convert and choose save location

All files are processed simultaneously using multiple CPU cores for maximum speed.

### Selecting Multiple Files

Instead of a folder, you can select specific files:

1. **Click "Select files"** in the Picmal window
2. **Hold ⌘ (Command)** while clicking to select multiple files
3. **Or hold ⇧ (Shift)** to select a range of files
4. Click **"Open"** to add them all to Picmal

## Batch Settings

### Applying Settings to All Files

When batch converting, settings apply to the entire queue:

- **Output Format**: All files convert to the same format
- **Quality**: Same quality setting for all files
- **Compression**: Uniform compression level

### Individual File Settings

Need different settings for some files? No problem:

1. Remove files that need different settings from the queue
2. Convert the main batch first
3. Add the remaining files and convert with different settings

## Preserving Folder Structure

When converting a folder with subfolders:

**Option 1: Flat Output**
- All converted files in a single folder
- Simpler organization
- Easier to find files

**Option 2: Preserve Structure** (Coming Soon)
- Maintains original folder hierarchy
- Subfolders are recreated in output location
- Keeps organization intact

## Mixed Format Conversion

Convert different file types in a single batch:

**Example: Photo Library**
- HEIC files → JPG
- PNG screenshots → WebP
- RAW photos → JPG

Picmal automatically detects each file's format and converts appropriately.

## Performance & Speed

### Conversion Speed Factors

Batch conversion speed depends on:

- **File Count**: More files = longer processing time
- **File Sizes**: Larger files take longer to process
- **Output Format**: Some formats (like AVIF) are slower to encode
- **Mac Hardware**: Apple Silicon Macs are faster than Intel Macs
- **Quality Settings**: Higher quality = slower conversion

### Optimization Tips

For faster batch conversions:

1. **Close other apps** - Free up CPU and RAM
2. **Use faster formats** - JPG and WebP are quick
3. **Lower quality** - 85% vs 95% saves time
4. **Batch by size** - Group similar-sized files together

### Typical Speeds

On an M1 MacBook Pro:

- **100 HEIC photos (12MP)** → JPG: ~1-2 minutes
- **50 PNG screenshots** → WebP: ~30 seconds
- **10 videos (1080p, 1 min each)** → MP4: ~5-10 minutes

## Batch Video Conversion

Convert multiple videos at once:

1. Add video files to Picmal
2. Select output format (MP4, MOV, etc.)
3. Choose quality preset (720p, 1080p, 4K)
4. Click Convert

**Note**: Video conversion is slower than image conversion due to larger file sizes and processing requirements.

Learn more in the [Video Conversion Guide](/docs/guides/video-conversion).

## Common Batch Workflows

### Website Asset Preparation

Converting images for a website:

1. Add all PNG/JPG images from your design folder
2. Convert to WebP format
3. Set quality to 85%
4. Save to website assets folder
5. Upload to your website

**Result**: 50-70% smaller files, faster page loads

### iPhone Photo Library

Converting all iPhone photos for backup:

1. Export photos from Photos app to a folder
2. Drag folder into Picmal
3. Convert HEIC → JPG (90% quality)
4. Save to external drive or cloud storage
5. Compatible with all devices

### Video Format Standardization

Converting mixed video formats to MP4:

1. Add videos from various sources (MOV, AVI, MKV)
2. Select MP4 as output format
3. Choose 1080p quality preset
4. Convert all to standardized format

## Managing Large Batches

### Queue Management

For very large batches (500+ files):

- **Progress tracking**: See how many files are done
- **Cancel anytime**: Stop conversion if needed
- **Resume later**: Add more files to continue

### Dealing with Errors

If a file fails to convert:

1. Picmal continues with remaining files
2. Failed files are marked in the queue
3. Review error messages for each failed file
4. Try converting problematic files individually

## Output Organization

### Naming Conventions

Converted files keep their original names:

- `photo.heic` → `photo.jpg`
- `screenshot.png` → `screenshot.webp`

If files already exist, numbers are appended:
- `photo.jpg`, `photo-1.jpg`, `photo-2.jpg`

### Batch Output Folders

Organize your output:

1. **By Date**: Create folders by date (e.g., `2024-01-14`)
2. **By Format**: Separate folders for each format
3. **By Project**: Keep project assets together

## Tips for Successful Batch Conversion

1. **Test First**: Convert a few files before processing hundreds
2. **Check Storage**: Ensure you have enough disk space
3. **Use Presets**: Save common settings for future batches
4. **Backup Originals**: Keep original files until you verify results
5. **Monitor Progress**: Stay nearby for very large batches

## Troubleshooting

**Conversion is slow:**
- Close other applications
- Reduce quality settings
- Process smaller batches

**Some files failed:**
- Check file isn't corrupted
- Verify format is supported
- Try converting individually

**Running out of space:**
- Clear up disk space before starting
- Use external drive for output
- Convert in smaller batches
