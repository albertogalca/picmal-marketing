# Converting Images

Learn how to convert images between different formats using Picmal. This guide covers all the image conversion features and best practices.

## Supported Image Formats

Picmal supports conversion between these popular image formats:

- **HEIC/HEIF** - Apple's high-efficiency format
- **JPG/JPEG** - Universal format, best compatibility
- **PNG** - Lossless format with transparency support
- **WebP** - Modern format with excellent compression
- **AVIF** - Next-gen format with superior compression
- **TIFF** - Professional format for high-quality images
- **BMP** - Uncompressed bitmap format
- **GIF** - Animated and static images
- **SVG** - Vector graphics (read-only)

## Basic Image Conversion

### Single Image Conversion

To convert a single image:

1. Drag the image file into Picmal
2. Select your desired output format from the dropdown
3. Adjust quality settings (optional)
4. Click "Convert" and choose save location

### Format Selection Guide

Choose the right format for your needs:

**For Web Use:**
- Use **WebP** for modern browsers (best compression)
- Use **JPG** for maximum compatibility
- Use **PNG** only when you need transparency

**For Printing:**
- Use **TIFF** for professional printing
- Use **PNG** for high-quality graphics
- Avoid JPG if quality is critical

**For Sharing:**
- Use **JPG** for photos (universal compatibility)
- Use **PNG** for screenshots with text
- Use **HEIC** to save space when sharing with Apple devices

## Quality Settings

The quality slider affects file size and image quality:

- **90-100%**: Maximum quality, larger files (printing, archival)
- **85-90%**: High quality, balanced size (recommended for most uses)
- **70-85%**: Good quality, smaller files (web images)
- **Below 70%**: Noticeable quality loss, very small files (thumbnails)

### Format-Specific Quality

Different formats handle quality differently:

- **PNG**: Lossless - quality slider doesn't affect visual quality
- **JPG**: Lossy - quality directly impacts both size and appearance
- **WebP/AVIF**: Advanced compression - maintains quality at lower file sizes

## Converting HEIC Photos

iPhone and iPad photos are saved as HEIC files. To convert them:

1. Connect your device or import photos to your Mac
2. Drag HEIC files into Picmal
3. Select **JPG** for universal compatibility
4. Set quality to **85-90%** for best results
5. Convert and share anywhere

**Why convert HEIC?**
- Not all devices and apps support HEIC
- JPG has universal compatibility
- Smaller JPG files are easier to share via email

Learn more in our [HEIC to JPG conversion guide](/blog/how-to-convert-heic-to-jpg-mac).

## Transparency Support

Some formats support transparent backgrounds:

**Formats with Transparency:**
- PNG ✓
- WebP ✓
- AVIF ✓
- GIF ✓

**Formats without Transparency:**
- JPG ✗ (converts to white background)
- TIFF ✗
- BMP ✗

When converting from a format with transparency to one without, transparent areas become white by default.

## Preserving Metadata

Picmal can preserve image metadata during conversion:

- **EXIF Data**: Camera settings, location, date
- **Color Profiles**: ICC profiles for accurate colors
- **Orientation**: Correct image rotation

By default, metadata is preserved. You can remove it in Settings > Privacy if needed for sharing images publicly.

## Batch Image Conversion

Convert multiple images at once:

1. Drag an entire folder into Picmal
2. All images are added to the conversion queue
3. Select output format (applies to all)
4. Set quality once for the entire batch
5. Click Convert - all files process simultaneously

Learn more in the [Batch Conversion Guide](/docs/guides/batch-conversion).

## Advanced Options

### Custom Output Locations

Choose where converted files are saved:

- **Custom Folder**: Select any folder on your Mac
- **Same as Source**: Save next to original files
- **Desktop**: Quick access to converted files

### File Naming

Converted files are automatically renamed:

- Original: `photo.heic`
- Converted: `photo.jpg`

If a file with the same name exists, a number is added: `photo-1.jpg`, `photo-2.jpg`

## Common Conversion Scenarios

### iPhone to Windows PC

Converting photos for Windows users:

1. Export photos from iPhone to Mac
2. Convert HEIC → JPG (85% quality)
3. Share via email, USB, or cloud storage

### Web Optimization

Optimizing images for websites:

1. Convert large images to WebP
2. Set quality to 85%
3. Typical 50-70% file size reduction
4. Faster website loading times

### Print Preparation

Preparing images for printing:

1. Convert to PNG or TIFF
2. Set quality to 95-100%
3. Ensure images are high resolution (300 DPI minimum)
4. Keep color profiles intact
