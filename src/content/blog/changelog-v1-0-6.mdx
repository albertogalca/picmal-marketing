## What's new in v1.0.6

- **Built-in update system:** Check for and install updates directly from the app without visiting Gumroad
- **Bug fixes:** Resolved conversion issues affecting EPS, AI, and WebP formats
- **Error reporting system:** Automatic error detection to help improve app stability (no personal data collected)
- **New website:** Picmal now has a dedicated home at [picmal.app](https://picmal.app)

## Major improvements

### Seamless updates

No more manual downloads from Gumroad or waiting for email notifications that might end up in spam. Simply go to Preferences and click "Check for Updates" to get the latest version instantly.

### Format conversion fixes

Fixed critical bugs that were affecting several image format conversions, particularly EPS, AI, and WebP files. These formats should now convert reliably without errors.

### Proactive error detection

A new error-reporting system has been implemented to identify and resolve issues faster. This system:

- Does not collect personal data or device information
- Only analyzes errors to improve app stability
- Helps prevent future conversion problems

## Looking ahead

### Upcoming features

The next major update will focus on:

- **Default conversion settings:** Set preferred output formats (e.g., always convert PNG to WebP)
- **Batch format changes:** Select multiple images and change output formats all at once
- **Homebrew installation:** Install and update Picmal via Homebrew (coming soon)

### Licensing system

A new licensing system is in development to replace Gumroad dependency. Current users will receive their licenses via email with no interruption to service.
