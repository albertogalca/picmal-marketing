title: "Built-in updates, format fixes and a new website"
pubDate: 2025-08-28
---

No more manual downloads from Gumroad. You can now check for and install updates directly from the app — just go to Preferences and click "Check for Updates".

Critical bugs affecting EPS, AI and WebP conversions have been fixed. These formats should now convert reliably without errors.

A new error-reporting system has been added to detect issues faster. It doesn't collect personal data or device information — it only captures error data to improve stability. Picmal also now has a dedicated website at [picmal.app](https://picmal.app).
