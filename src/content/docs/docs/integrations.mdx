## Drag & Drop

Drop files onto Picmal in three ways:

- **App window** — Drop files directly into the main window
- **Dock icon** — Drop files onto the Picmal icon in your Dock
- **Menu bar icon** — Drop files onto the menu bar icon (when menu bar mode is enabled)

You can drop individual files or entire folders.

## Finder Services (Right-Click Menu)

Picmal adds two services to Finder's right-click menu:

1. **Convert Files** — Opens selected files in Picmal in Convert mode
2. **Compress Files** — Opens selected files in Picmal in Compress mode

Select files in Finder, right-click, and find these under **Services** (or **Quick Actions**).

## Shortcuts App

Picmal provides two actions for Apple's Shortcuts app, so you can build automated workflows.

### Convert Files

| Parameter     | Description                 |
| ------------- | --------------------------- |
| Files         | The files to convert        |
| Output format | Target format               |
| Preset        | Compression preset to apply |

### Compress Files

| Parameter       | Description                                    |
| --------------- | ---------------------------------------------- |
| Files           | The files to compress                          |
| Preset          | Compression preset                             |
| Custom quality  | Quality value (1–100) when using Custom preset |
| Remove metadata | Strip metadata from output                     |

Use these to build automations like "compress every screenshot I take" or "convert HEIC photos to JPEG when added to a folder."

## Menu Bar Mode

Enable **Keep in Menu Bar** in Settings to add a Picmal icon to your menu bar. The app stays running in the background even when the main window is closed.

Menu bar keyboard shortcuts:

| Key | Action             |
| --- | ------------------ |
| O   | Open Picmal window |
| ,   | Open Settings      |
| Q   | Quit Picmal        |

## Start at Login

Enable **Start at Login** in Settings so Picmal launches automatically when you log in. Combined with menu bar mode and watched folders, this gives you always-on automatic file processing.
