# Quick Start Guide

This guide will walk you through your first conversion using Picmal. You'll learn the basics and be converting files in under a minute.

## Your First Conversion

### Step 1: Launch Picmal

Open Picmal from your Applications folder. You'll see the main window with a large drop zone in the center.

### Step 2: Add Your Files

There are three ways to add files to Picmal:

1. **Drag & Drop** - Drag files directly onto the window (easiest method)
2. **Click the drop zone** - Click "Select files" to browse for files
3. **Use the menu** - Go to File > Add Files (⌘O)

### Step 3: Choose Output Format

After adding your files, you'll see them listed in the conversion queue. For each file or batch:

1. Click the **format dropdown** (shows current format by default)
2. Select your desired output format (e.g., JPG, PNG, WebP, MP4)
3. Adjust quality settings if needed (optional)

### Step 4: Start Converting

Once you've chosen your output format:

1. Click the **"Convert"** button
2. Choose where to save your converted files
3. Wait for the conversion to complete (usually just seconds)

That's it! Your files are now converted and saved to your chosen location.

## Example: Convert HEIC to JPG

Here's a common workflow - converting iPhone photos (HEIC) to JPG:

1. **Add photos** - Drag your HEIC photos onto Picmal
2. **Select JPG** - Choose JPG from the format dropdown
3. **Set quality** - Use the slider to set quality (85-90 recommended)
4. **Convert** - Click Convert and choose your save location

Your photos are now in JPG format and ready to share anywhere.

## Batch Conversion

Need to convert multiple files at once? Picmal makes it easy:

1. **Select multiple files** - Drag a folder or multiple files into Picmal
2. **Same format for all** - Choose one output format for the entire batch
3. **Convert in bulk** - All files are converted simultaneously

Learn more in the [Batch Conversion Guide](/docs/guides/batch-conversion).

## Compression vs Conversion

Picmal can both **convert** (change format) and **compress** (reduce file size):

- **Convert**: Change from one format to another (e.g., HEIC → JPG)
- **Compress**: Keep the same format but reduce file size
- **Both**: Convert to a smaller format (e.g., PNG → WebP for 50% smaller files)

- **Format Selection**: Use WebP or AVIF for the best compression
- **Preview**: Check one file before batch converting hundreds
