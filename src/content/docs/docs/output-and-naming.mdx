## Where files go

By default, converted and compressed files are saved in the same folder as the originals.

## File naming

### Conversion

Converted files use the original filename with the new extension:

```
photo.heic → photo.jpeg
```

You can add a prefix or suffix to the filename in settings:

```
Prefix: "web_"  →  web_photo.jpeg
Suffix: "_2x"   →  photo_2x.jpeg
```

### Compression

Compressed files keep their original extension and add a `_compressed` suffix by default:

```
photo.jpeg → photo_compressed.jpeg
```

The compression suffix is configurable in settings. You can also set a prefix.

## Overwrite warning

Picmal does not overwrite original files. If a file with the same name already exists, the new file is created alongside it with the appropriate suffix.

If you remove the default suffix and a file with the same name exists, be careful — check your naming settings to avoid conflicts.

## Default format mapping

You can configure default output formats per input type. For example, you can set all HEIC files to convert to JPEG automatically. This is useful for drag-and-drop workflows where you always want a specific conversion.

Configure default mappings in **Settings → Output**.
