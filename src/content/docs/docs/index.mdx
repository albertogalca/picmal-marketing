## What Can You Do with Picmal?

- **Convert Images**: Transform images between HEIC, JPG, PNG, WebP, AVIF, and more
- **Compress Images**: Reduce file sizes while maintaining quality
- **Convert Videos**: Change video formats and codecs with ease
- **Batch Processing**: Convert hundreds of files at once
- **Drag & Drop**: Simple, intuitive interface for quick conversions
