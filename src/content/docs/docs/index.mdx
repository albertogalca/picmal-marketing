Picmal let you batch convert and compress your images, videos and audios offline on your Mac. Beautiful, private, and straightforward.

I built it because I couldn't find an media files converter that felt right. Everything out there had the same problems:

- Terminal only tools when I just wanted a clean interface
- Online services that wanted me to upload my private media files to external servers
- They didn't support batch conversion

So I built Picmal around a four core things:

1. **Works 100% offline.** **Everything stays on your Mac.** Your media files never leave your computer. No uploads, no cloud syncing, no internet required. What you convert is yours alone.
2. **Made for people, not terminals.** A beautiful, straightforward interface designed like a Mac app should be. Install it, open it, use it.
3. **Private by design.** I don't track your media files, store your data, or upload anything anywhere.
4. **Built with intention.** Every feature has a reason. Nothing unnecessary. Just what you need to convert and compress media files well.

## Key Features

- Convert one or more files across 90+ formats:
    - Images: JPEG, PNG, GIF, HEIC, WebP, AVIF, PSD, RAW, SVG, PDF, and 20+ more
    - Videos: MP4, MOV, AVI, MKV, WebM, and 15+ more (including video-to-GIF)
    - Audio: MP3, WAV, AAC, FLAC, OGG, OPUS, and 35+ more

- Compress all formats with quality control:
    - Images: JPEG, PNG, WebP, GIF, SVG, TIFF, HEIC, AVIF, PDF, and more
    - Videos: All formats with H.264 encoding
    - Audio: All formats with AAC encoding

- Remove metadata from images for smaller file sizes.
- Auto-compress option to compress files directly after converting.
- Batch processing with individual progress tracking.
