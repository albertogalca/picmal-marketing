## Images

### Common formats

| Format | Input | Output | Notes                              |
| ------ | ----- | ------ | ---------------------------------- |
| JPEG   | Yes   | Yes    | Most widely supported photo format |
| PNG    | Yes   | Yes    | Lossless with transparency         |
| GIF    | Yes   | Yes    | Animated and static                |
| WebP   | Yes   | Yes    | Modern web format                  |
| HEIC   | Yes   | Yes    | Apple's default photo format       |
| AVIF   | Yes   | Yes    | Next-gen web format                |
| BMP    | Yes   | Yes    | Uncompressed bitmap                |
| TIFF   | Yes   | Yes    | Print and archival                 |
| PDF    | Yes   | Yes    | Document/image hybrid              |
| SVG    | Yes   | Yes    | Vector graphics                    |
| ICO    | Yes   | Yes    | Favicons and icons                 |

| --------------------- | ----- | ------ | ----------------- |

| QOI                   | Yes   | Yes    | Quite OK Image    |

| PICT                  | Yes   | Yes    | Legacy Mac format |
| QTIF                  | Yes   | Yes    | QuickTime Image   |

### Input-Only formats

These formats can be read and converted to other formats, but Picmal cannot write them.

| Format | Notes                   |
| ------ | ----------------------- |
| AI     | Adobe Illustrator       |
| EPS    | Encapsulated PostScript |
| ARW    | Sony RAW                |
| CR2    | Canon RAW               |
| DNG    | Adobe Digital Negative  |
| NEF    | Nikon RAW               |
| RAF    | Fujifilm RAW            |

RAW and vector formats are converted using bundled tools — no extra software needed.
