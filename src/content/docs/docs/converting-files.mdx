---
title: Converting Files
---

Convert mode changes a file from one format to another. For example, HEIC to JPEG, WAV to MP3, or MOV to MP4.

## How to Use

1. Make sure you're on the **Convert** tab
2. Drop files into the window or click **Add Files**
3. Select the output format
4. Click **Convert**

## Optional Compression During Conversion

You can apply compression as part of the conversion. Adjust the quality slider or pick a preset before converting. This lets you change format and reduce file size in one step.

## Format Compatibility

Picmal converts within the same media type:

- **Image → Image** (e.g., PNG → JPEG, HEIC → WebP)
- **Audio → Audio** (e.g., WAV → MP3, FLAC → AAC)
- **Video → Video** (e.g., MOV → MP4, AVI → WebM)

You can't convert across types (e.g., image to audio).

## Metadata Control

Choose how metadata is handled during conversion:

| Mode | What It Does |
|------|-------------|
| Strip all | Removes all metadata for smallest file size |
| Keep essential | Preserves orientation, color profile, and copyright |
| Keep all | Preserves all original metadata |

See [Supported Formats](/docs/supported-formats) for the full list of input and output formats.
