## What's new in v1.0.8

- Added batch output format selection to apply a single format to multiple files at once.
- Added notifications when file conversions are complete.

## Major improvements

### Batch output format selection

![Batch outuput format selection feature](/images/changelog/1.0.8/multiple_output_update.png)

Apply a single format to multiple files at once. There is no need to set the format for each file individually anymore. Select multiple files and apply one output format to all of them at once to save time and clicks.

### Conversion notifications

![Notifications active](/images/changelog/1.0.8/notifications_picmal.png)

Picmal will now notify you when your files have finished converting. Whether you’re working on a single file or a batch, you’ll get a quick alert so you can move on to the next task without constantly checking.

![Conversion complete notification](/images/changelog/1.0.8/notification_complete.png)
