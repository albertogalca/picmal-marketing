# Picmal - Image Converter for macOS

> Fast, private, batch image conversion and compression for Mac

## Overview

Picmal is a native macOS application for converting and compressing images between formats including HEIC, JPG, PNG, WebP, AVIF, TIFF, BMP, GIF, and SVG.

## Key Features

- Batch conversion of multiple images simultaneously
- Support for 10+ image formats (HEIC, JPG, PNG, WebP, AVIF, TIFF, BMP, GIF, SVG)
- Drag-and-drop interface
- Quality control and compression settings
- 100% offline and private - no cloud upload
- Native macOS app (M1/M2/M3 optimized)
- Free to download and use

## Use Cases

- Convert iPhone HEIC photos to JPG
- Compress PNG files for web use
- Batch convert images for email or sharing
- Convert between modern formats (WebP, AVIF)
- Prepare images for presentations or documents

## Pricing

- Free download with full features
- Available on macOS 11.0 and later

## Technical Details

- Native macOS application
- Built for Apple Silicon and Intel Macs
- Supports batch processing
- Preserves EXIF metadata when possible
- Local processing - no internet required
