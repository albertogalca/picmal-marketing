title: "Auto compress mode and custom naming for compressed files"
pubDate: 2025-09-29
---

Enable auto compress mode in Preferences > Files and files will start compressing the moment you drop them — no need to press any buttons. Perfect for batch processing workflows.

You can now add custom prefixes and suffixes to compressed output files in Preferences > Output, or leave the fields blank to overwrite originals. A "Clear settings" button has been added to reset compression quality settings to defaults.

We also fixed an issue where files weren't being compressed correctly in the output.
