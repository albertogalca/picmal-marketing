title: "SVG support, 40% faster conversions and lower memory usage"
pubDate: 2025-07-11
---

SVG files are now supported as an input format — great for designers who need to convert vector icons and illustrations to raster formats like PNG or JPEG.

The conversion engine has been rewritten for better performance, delivering roughly 40% faster processing times across the board. Memory usage has also been reduced by about 30% when handling large images, which means smoother operation on older Mac models.

Batch processing now runs files in parallel when system resources allow, and the UI stays responsive even during intensive conversion tasks.
