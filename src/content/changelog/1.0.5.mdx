title: "Custom file naming and image metadata display"
pubDate: 2025-07-21
---

You can now add custom prefixes and suffixes to converted filenames — handy for organising batches or adding timestamps. Configure these in the conversion settings.

This release also adds an image metadata viewer. Right-click any image in Picmal and select "Show Metadata" to see EXIF data, colour profiles, camera settings, GPS data and other file properties.
