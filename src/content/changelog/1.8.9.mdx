Ten files in, three broken, and the summary said "Done · 7 files converted". This release is about the other three. The bottom bar counts the failures, the Run Again button turns into Retry Failed, and pressing it re-runs those files alone while everything that finished keeps its tick. Converting an icon file also stops fanning out eight images into the wrong folder, and every audio quality preset now produces a different file, which they should have been doing all along.

### New features

- **Double-click a file to show it in Finder.** Works in every tool list, on the converted file once it exists and on the original before that. The right-click menu item stays where it was. See [managing the queue](/docs/managing-the-queue#right-click-menu).
- **Retry only the files that failed.** When a batch ends with failures, the Run Again button becomes Retry Failed, with the count. Press it and Picmal re-runs those files alone. The ones that finished keep their tick and their savings figure, and nothing gets encoded twice. See [when the batch is done](/docs/managing-the-queue#when-the-batch-is-done).

### Improvements

- **Converting an icon file gives you one image, not eight.** An `.icns` holds every size from 16 px up to 1024, and Picmal used to write all of them out, next to the original file instead of in your output folder. It now takes the largest and leaves it where you asked. **Settings → Images → Icon output size** picks a different one, or all of them if that is what you were after, and the command line has the same choice on `--icon-size`. Multi-page PDFs land in your output folder now too. See [Apple icon files](/docs/converting-files#apple-icon-files).
- **A batch with failures says so.** The summary under the file list used to read "Done · 7 files converted" when 10 went in and 3 broke, and the only place the 3 showed up was the system notification. It now reads "Finished · 7 files converted · 3 failed", under a warning glyph instead of the tick.
- **An unlicensed Convert button opens the license window.** Before, it was greyed out with a tooltip and nothing else, in every tool. Now the click lands, Picmal asks for the license, and once you have one the run starts as usual. See [license](/docs/license#activate-from-the-run-button).
- **The command line closes every batch with a `completed` event.** In JSON mode, `convert`, `compress`, `crop`, `split-pdf`, and `remove-background` now end the stream with `produced` and `failed` counts, so a script can tell a finished batch from a process that died. `remove-background` also exits `9` on a partial batch and `2` on bad arguments, like the other commands. See [JSON output](/docs/cli#json-output).
- **The Preset column is now the Quality column.** It never chose the output format, only the bitrate and codec recipe for it, and the old name led people to expect a second file type. The tooltip says so now too, in Convert and Compress both. See [a preset per file](/docs/compressing-files#a-preset-per-file).

### Bug fixes

- **Fixed overwriting a file in a protected folder failing the whole batch.** Converting or compressing in place inside Desktop, Documents, or Downloads could hit "You don't have permission to save the file X in the folder Y" and stop there, because the final write step needs access to the folder, not just the file. Picmal now falls back to writing the new content directly into the file it already has permission for.
- **Fixed audio conversion presets not changing the file.** Convert always encoded audio at maximum quality regardless of which preset you picked, so Voice Memo, Podcast, and Music all came out the same. Each preset's quality now reaches the encoder.
- **Fixed every MP3 quality preset sounding the same.** A conflicting pair of ffmpeg flags collapsed them all to the same ~245 kbps, so a 64 kbps "Voice memo" came back as a 21 MB file. The presets are distinct again.
- **Fixed a sample rate the target format can't hold failing the encode.** Asking for 96 kHz into MP3, or 44.1 kHz into Opus, aborted with a 0-byte file. Picmal now converts at the nearest rate the codec supports and flags it in the Convert table, in the app and from the command line. See [sample rate](/docs/audio-and-video#sample-rate).
