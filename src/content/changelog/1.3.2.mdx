pubDate: 2026-01-15

PNG and SVG compression now produces significantly smaller files while maintaining the same visual quality. If you rely on these formats for web assets or icons, you should see a noticeable improvement.

This release also fixes several crashes that affected macOS 14 users, particularly during the initial setup experience. Other minor stability fixes are included.
