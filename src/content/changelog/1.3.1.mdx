title: "Better compression, clearer errors and background launch fix"
pubDate: 2025-12-26
---

Image compression quality has been improved across all supported formats, producing smaller files without a visible loss in quality.

Error messages when switching between Compress and Convert modes are now much clearer, so you'll know exactly what went wrong instead of seeing a generic failure. Video compression has also been fixed — earlier versions weren't always reducing file sizes — and encoding performance is noticeably faster.

If you use "Keep in Menu Bar", the app now correctly starts in the background at login without briefly showing the main window.
