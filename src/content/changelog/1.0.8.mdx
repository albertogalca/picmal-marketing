title: "Batch format selection and conversion notifications"
pubDate: 2025-09-11
---

You can now select multiple files and apply one output format to all of them at once — no need to set each file individually. This saves a lot of time when processing large batches.

![Batch output format selection feature](/images/changelog/1.0.8/multiple_output_update.png)

Picmal will also notify you when your files have finished converting, so you can move on to other tasks without constantly checking back.

![Notifications active](/images/changelog/1.0.8/notifications_picmal.png)

![Conversion complete notification](/images/changelog/1.0.8/notification_complete.png)
