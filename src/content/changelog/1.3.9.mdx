version: "1.3.9"
title: "Smart format memory and improved clipboard overlay"
pubDate: 2026-02-26
---

Picmal now remembers the last output format you selected for each input type. Drop a new file and it automatically picks up right where you left off — no need to reselect the format every time. If you always convert HEIC to JPG or PNG to WebP, it just works.

The clipboard overlay also got a nice upgrade. It now disappears on its own after a configurable timeout, set to 5 seconds by default, so it stays out of your way without needing a manual dismiss. And the overlay is no longer captured in macOS screenshots, keeping your screen grabs clean.
