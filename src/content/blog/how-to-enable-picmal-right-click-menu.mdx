One of Picmal's most convenient features is the ability to convert or compress images directly from the Finder right-click menu. Instead of opening the app and dragging files, you can simply right-click any image and select "Convert with Picmal" or "Compress with Picmal" to process it instantly.

This guide shows you how to enable these Services on your Mac.

## What Are macOS Services?

Services are system-level integrations that allow apps to add options to macOS context menus. When enabled, Picmal's services add two options when you right-click on image files:

- **Convert with Picmal** - Opens the selected images in Picmal for format conversion
- **Compress with Picmal** - Opens the selected images in Picmal for compression

These options work with single files or multiple selections, making batch processing incredibly fast.

## How to Enable Picmal's Right-Click Options

### Step 1: Open System Settings

1. Click the **Apple menu** () in the top-left corner of your screen
2. Select **System Settings** (or System Preferences on older macOS versions)

### Step 2: Navigate to Keyboard Shortcuts

1. Click **Keyboard** in the sidebar
2. Click **Keyboard Shortcuts...**
3. Select **Services** from the left panel

### Step 3: Enable Picmal Services

1. Scroll down to the **Files and Folders** section
2. Look for entries named:
   - **Convert with Picmal**
   - **Compress with Picmal**
3. Check the boxes next to each option you want to enable
4. Close System Settings

![macOS System Settings showing Keyboard Shortcuts with Picmal Services enabled in the Files and Folders section](/images/blog/how-to-enable-picmal-right-click-menu/keyboard-preferences.webp)

## How to Use the Right-Click Options

Once enabled, using Picmal from the context menu is straightforward:

### Converting Images

1. Select one or more image files in Finder
2. Right-click (or Control-click) on the selection
3. Choose **Convert with Picmal** from the context menu
4. Picmal opens with your images ready for conversion
5. Select your target format and convert

### Compressing Images

1. Select one or more image files in Finder
2. Right-click on the selection
3. Choose **Compress with Picmal**
4. Picmal opens with your images in compression mode
5. Adjust compression settings and process
