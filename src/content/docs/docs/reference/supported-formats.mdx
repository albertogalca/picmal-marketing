# Supported Formats

Picmal supports a wide range of image and video formats for both input (import) and output (export). This reference guide lists all supported formats and their capabilities.

## Image Formats

### HEIC / HEIF
**High Efficiency Image Format**

- **Extension**: `.heic`, `.heif`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Transparency**: ✗ No
- **Compression**: Lossy

Apple's modern image format used by iPhone and iPad. Offers better compression than JPG while maintaining quality. Not universally supported outside Apple ecosystem.

**Best for**: iPhone photos, modern Apple devices

---

### JPG / JPEG
**Joint Photographic Experts Group**

- **Extension**: `.jpg`, `.jpeg`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Transparency**: ✗ No
- **Compression**: Lossy

The most widely supported image format. Universal compatibility across all devices and platforms. Good compression for photos.

**Best for**: Photos, web images, maximum compatibility

---

### PNG
**Portable Network Graphics**

- **Extension**: `.png`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Transparency**: ✓ Yes
- **Compression**: Lossless

Lossless format with transparency support. Larger file sizes than JPG but no quality loss. Ideal for graphics, logos, and screenshots.

**Best for**: Screenshots, graphics with text, images needing transparency

---

### WebP
**Web Picture Format**

- **Extension**: `.webp`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Transparency**: ✓ Yes
- **Compression**: Lossy & Lossless

Modern web format developed by Google. Excellent compression with good quality. Supported by all modern browsers.

**Best for**: Web images, reducing file sizes, modern websites

---

### AVIF
**AV1 Image File Format**

- **Extension**: `.avif`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Transparency**: ✓ Yes
- **Compression**: Lossy & Lossless

Next-generation image format with superior compression. Even smaller files than WebP with similar or better quality. Growing browser support.

**Best for**: Cutting-edge web projects, maximum compression

---

### TIFF
**Tagged Image File Format**

- **Extension**: `.tiff`, `.tif`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Transparency**: ✗ No
- **Compression**: Lossless or Uncompressed

Professional format used in printing and publishing. Large file sizes but excellent quality. Preserves maximum detail.

**Best for**: Professional printing, archival, high-quality workflows

---

### BMP
**Bitmap Image File**

- **Extension**: `.bmp`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Transparency**: ✗ No
- **Compression**: Uncompressed

Simple, uncompressed format. Very large file sizes. Universal support on Windows.

**Best for**: Legacy Windows applications, simple graphics

---

### GIF
**Graphics Interchange Format**

- **Extension**: `.gif`
- **Input**: ✓ Yes
- **Output**: ✓ Yes (static only)
- **Transparency**: ✓ Yes (binary)
- **Compression**: Lossless (256 colors max)

Legacy format supporting animation. Limited to 256 colors. Binary transparency (no semi-transparent pixels).

**Best for**: Simple animations, legacy web graphics

---

### SVG
**Scalable Vector Graphics**

- **Extension**: `.svg`
- **Input**: ✓ Yes (converts to raster)
- **Output**: ✗ No
- **Transparency**: N/A
- **Compression**: N/A

Vector graphics format. Picmal can import SVG and convert to raster formats (PNG, JPG, etc.) but cannot export to SVG.

**Best for**: Icons, logos (when converting to raster)

---

## Video Formats

### MP4
**MPEG-4 Part 14**

- **Extension**: `.mp4`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Codecs**: H.264, H.265/HEVC

Universal video format with excellent compatibility. Supported everywhere. Good compression with high quality.

**Best for**: Web videos, sharing videos, maximum compatibility

---

### MOV
**QuickTime Movie**

- **Extension**: `.mov`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Codecs**: Various

Apple's native video format. High quality, good for editing. May have compatibility issues on non-Apple platforms.

**Best for**: Mac video editing, iPhone/iPad videos

---

### MKV
**Matroska Video**

- **Extension**: `.mkv`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Codecs**: Various

Open-source container format. Supports multiple audio tracks and subtitles. Not universally supported.

**Best for**: High-quality video collections, archival

---

### AVI
**Audio Video Interleave**

- **Extension**: `.avi`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Codecs**: Various

Legacy Windows video format. Large file sizes. Wide compatibility on older systems.

**Best for**: Legacy applications, older Windows systems

---

### WEBM
**Web Media File**

- **Extension**: `.webm`
- **Input**: ✓ Yes
- **Output**: ✓ Yes
- **Codecs**: VP8, VP9

Open web video format. Good compression, designed for web use. Supported by modern browsers.

**Best for**: Web videos, streaming

---

## Audio Formats

### MP3
**MPEG Audio Layer 3**

- **Extension**: `.mp3`
- **Input**: ✓ Yes (from video)
- **Output**: ✓ Yes (extract audio)

Universal audio format. Good compression, wide compatibility.

**Best for**: Music, podcasts, extracted audio

---

### AAC
**Advanced Audio Coding**

- **Extension**: `.aac`, `.m4a`
- **Input**: ✓ Yes (from video)
- **Output**: ✓ Yes (extract audio)

Modern audio format. Better quality than MP3 at similar bitrates. Used in MP4 videos.

**Best for**: High-quality audio, modern devices

---

### WAV
**Waveform Audio File Format**

- **Extension**: `.wav`
- **Input**: ✓ Yes (from video)
- **Output**: ✓ Yes (extract audio)

Uncompressed audio format. Very large files but maximum quality.

**Best for**: Audio editing, professional audio work

---

## Format Comparison

### File Size Comparison (for a typical photo)

| Format | Quality | File Size | Compatibility |
|--------|---------|-----------|---------------|
| Original | 100% | 12 MB | - |
| JPG 90% | Excellent | 2.5 MB | Universal |
| PNG | Lossless | 15 MB | Universal |
| WebP 90% | Excellent | 1.5 MB | Modern browsers |
| AVIF 90% | Excellent | 1.2 MB | Newer browsers |
| HEIC | Excellent | 2 MB | Apple devices |

### When to Use Each Format

**Maximum Compatibility**: JPG
**Best Compression**: AVIF
**Transparency Needed**: PNG or WebP
**Professional Use**: TIFF
**Web Images**: WebP or AVIF
**Apple Devices**: HEIC

## Format Limitations

### Import Limitations

- **RAW formats**: Not supported (convert with Photos app first)
- **Animated GIF**: Imports as static image
- **SVG**: Converts to raster (cannot preserve vectors)
- **PDF**: Not supported for image import

### Export Limitations

- **GIF**: Cannot export animated GIFs
- **SVG**: Cannot export vector graphics
- **RAW**: Cannot export to camera RAW formats
- **ICO**: Not supported for output
